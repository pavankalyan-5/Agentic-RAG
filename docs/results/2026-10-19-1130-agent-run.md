**Answer:**

> You can run code when the Starlette application starts up and shuts down by registering a lifespan handler. This is done by defining an async context manager function that yields control during the application's lifespan. For example:
> 
> ```python
> import contextlib
> from starlette.applications import Starlette
> 
> @contextlib.asynccontextmanager
> async def lifespan(app):
>     async with some_async_resource():
>         print("Run at startup!")
>         yield
>         print("Run on shutdown!")
> 
> routes = [
>     ...
> ]
> 
> app = Starlette(routes=routes, lifespan=lifespan)
> ```
> 
> Starlette will run the code before the `yield` at startup and the code after the `yield` on shutdown. The application will not start serving requests until the lifespan startup code has run, and the shutdown code runs once all connections are closed and background tasks complete. Consider using `anyio.create_task_group()` for managing asynchronous tasks within the lifespan handler.[72]

**Answer:**

> To limit the size of uploaded files in multipart forms, you can configure the `max_body_size` parameter on the application, router, mount, or route, or use the `RequestBodyLimitMiddleware`. This limit applies to the total request body size, including uploaded files and multipart encoding overhead [828][882][308].
> 
> Additionally, when parsing the form data with `request.form()`, you can limit the size of each non-file field using the `max_part_size` parameter, but uploaded files themselves are spooled to temporary storage and are not limited by `max_part_size` [308].
> 
> Example of setting `max_body_size` on a route:
> ```python
> app = Starlette(
>     routes=[
>         Route("/upload", upload, methods=["POST"], max_body_size=100 * 1024 * 1024),
>     ],
>     max_body_size=10 * 1024 * 1024,
> )
> ```
> 
> Example of using `RequestBodyLimitMiddleware`:
> ```python
> from starlette.middleware import Middleware
> from starlette.middleware.body_limit import RequestBodyLimitMiddleware
> 
> middleware = [
>     Middleware(RequestBodyLimitMiddleware, max_body_size=10 * 1024 * 1024)
> ]
> 
> app = Starlette(routes=routes, middleware=middleware)
> ```
> These approaches ensure that requests exceeding the specified size receive a `413 Content Too Large` response [828][882][308].

**Answer:**

> You can run code when the Starlette application starts up and shuts down by registering a lifespan handler. This is done by defining an async context manager function that yields control during the application's lifespan. For example:
> 
> ```python
> import contextlib
> from starlette.applications import Starlette
> 
> @contextlib.asynccontextmanager
> async def lifespan(app):
>     async with some_async_resource():
>         print("Run at startup!")
>         yield
>         print("Run on shutdown!")
> 
> routes = [
>     ...
> ]
> 
> app = Starlette(routes=routes, lifespan=lifespan)
> ```
> 
> Starlette will run the code before the `yield` at startup and the code after the `yield` on shutdown. The application will not start serving requests until the lifespan startup code has run, and the shutdown code runs once all connections are closed and background tasks complete. Consider using `anyio.create_task_group()` for managing asynchronous tasks within the lifespan handler.[72]
